# 声望药房 ShengWangShop

宁州声望达到 **声名远扬** 后：

1. **大地图拜访门派时**，门派对话菜单（拜访长老/离开）中新增 **「购买药材」** 选项，点击直接打开该门派的药房购买面板；
2. 各大门派药房（场景里的"XX库房"）改用 **灵石** 购买药材，不再需要本门贡献货币。

## 背景

原版五大门派（竹山宗、离火门、金虹剑派、星河剑派、化尘教）的药房/库房使用**本门贡献货币**购买：

| 门派 | 场景 | 贡献货币 |
|---|---|---|
| 竹山宗 | 竹山宗库房 | 沧元丹 |
| 离火门 | 离火门库房 | 火晶 |
| 金虹剑派 | 金虹剑派库房 | 元灵石 |
| 星河剑派 | 星河剑派库房 | 寒玉 |
| 化尘教 | 化尘教库房 | 砂晶 |

非本门弟子没有这些货币，原版只能看不能买。本 mod 让**声名远扬**（宁州声望 500 起，等级 6）的修士凭名望在任何门派药房直接用灵石购买，价格与原版贡献价等价换算（游戏隐含定价 1 贡献 = 100 灵石，即按物品底价购买；例如一袋银月花 = 18 沧元丹 = 1800 灵石）。

此外，原版拜访其他门派时无法进入其药房场景，本 mod 在门派拜访对话菜单中提供 **「购买药材」** 入口：玩家站在门派节点上与门派弟子对话时，菜单会多出一个选项，点击即打开该门派的库房购买面板（灵石支付），无需加入该门派。

声望未达标时不介入：菜单不出现「购买药材」，药房行为与原版完全一致（本门弟子仍用贡献货币购买）。

## 配置项（BepInEx 配置文件 `BepInEx/config/chiqingsan.mcs.ShengWangShop.cfg`）

| 配置 | 默认值 | 说明 |
|---|---|---|
| `Plugin.Enabled` | `true` | 总开关 |
| `Plugin.MinShengWangLevel` | `6` | 所需宁州声望等级（6=声名远扬，7=誉满天下；等级区间见游戏内声望面板） |
| `Plugin.AddBuyHerbsOption` | `true` | 是否在门派拜访对话菜单中追加「购买药材」选项 |
| `Plugin.MaxBuyPerAction` | `999` | 单次购买的最大数量。**不建议调大**：游戏获得物品是逐袋处理（"一袋XX"会逐袋拆开），数万数量会导致游戏卡死（详见下文"性能说明"） |

## 性能说明

购买药材时游戏对"一袋XX"类草药的处理是**逐袋拆解**：每袋执行一次完整的"使用物品"流程（写日志、查配置、反射调用、发放袋内散装药材、合并提示）。这是游戏原版机制，mod 无法绕开。

- 原版药房用门派贡献货币，一次最多买几十袋，无感知；
- 改用灵石后，若不做限制，一次可买几十万袋（购买数量上限来自灵石余额），逐袋处理会让游戏直接卡死。

因此 mod 将**单次购买数量上限限制为 999**（`MaxBuyPerAction` 可调，但调大后确认购买时会有可感知卡顿甚至卡死）。想要更多请分多次购买。

另外两处针对性能的优化：

- **打开面板不重建**：药房商品固定、无库存概念，mod 会缓存已渲染的面板——同一门派的药房再次打开时只更新灵石数字，不重建约 30 个商品图标（原实现每次打开都销毁重建，造成每次打开面板的卡顿）；场景/门派或商品集合变化时自动重建
- **购买后不重建**：购买确认后只更新顶部灵石数字，不重建整个面板（原实现每次购买都会重建，造成购买时的卡顿感）

## 安装

本地 mod 方式（与"交易防崩补丁"相同）：

1. 打开游戏目录 `本地Mod测试\`
2. 新建文件夹 `ShengWangShop`，其下再建 `plugins`
3. 放入 `ShengWangShop.dll`：

```
本地Mod测试\
  ShengWangShop\
    plugins\
      ShengWangShop.dll
```

4. 启动游戏，BepInEx 日志出现 `声望药房已加载` 即生效

前置：工坊 BepInEx（ID 2824349934）。理论上不与其他 mod 冲突——只接管了 `UIMenPaiShop.RefreshUI` 一处，且声望未达标时完全走原版。

## 构建与代码结构

前置：.NET SDK（LangVersion 10）；本机装有游戏与工坊 BepInEx。路径在 `ShengWangShop.csproj` 中配置。

```
dotnet build -c Release
```

产物：`bin\Release\ShengWangShop.dll`

```
ShengWangShop.csproj        工程文件（引用路径按本机配置）
Plugin.cs                   BepInEx 入口 + 配置项 + 注册 patch
MenPaiShopPatch.cs          Harmony Prefix patch UIMenPaiShop.RefreshUI（灵石药房渲染）+ Close 清理
SectVisitOptionPatch.cs     Harmony Postfix patch Fungus.MenuDialog.AddOption（拜访菜单注入"购买药材"）
```

## 实现说明

**药房灵石化**：`UIMenPaiShop.RefreshUI` 是门派药房打开/购买后的刷新入口。补丁在其 Prefix 中判断宁州声望等级：

- 未达标 → 放行原版方法（原版行为）
- 达标 → 跳过原版，执行 mod 自己的渲染（流程复刻原版，仅支付路径不同）：
  - 价格 = `ceil(物品底价 / percent) × 100`（原版贡献价 × 100，与贡献货币等价）
  - 购买确认后 `Player.AddMoney(-总价)`（灵石走 `money` 字段，与游戏自带兑换商店 `UIDuiHuanShop` 处理灵石的官方分支一致），入包、提示、刷新与原版相同
  - 顶部货币栏显示灵石图标与当前灵石数
- 渲染过程抛异常时自动回退原版逻辑并写日志，避免因数据变动把药房弄挂

**拜访菜单入口**：门派拜访对话是 Fungus 流程（`MenuDialog`），选项为"拜访长老/离开"。补丁在 `MenuDialog.AddOption` 添加"拜访长老"时（仅在 AllMaps 大地图场景、声望达标时），通过 MenuDialog 内部接口追加一个"购买药材"按钮：

- 门派识别：读取玩家当前所在大地图节点对象子树中的名牌文本（"竹山宗/离火门/金虹剑派/星河剑派/化尘教"），失败时回退到当前对话文本匹配；识别不到则不注入选项（写日志）
- 点击后关闭对话菜单，设置 `OverrideShopScene` 为该门派库房场景（S115/S125/S135/S145/S155），调用 `UIMenPaiShop.Show() + RefreshUI()`——由上述灵石渲染逻辑渲染对应门派的库房；关闭面板时清除覆盖
